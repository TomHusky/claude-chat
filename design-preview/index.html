帮我看看订单回填任务有没有幂等问题，重复执行会不会写重数据

我查了订单回填这块，结论先说：当前实现不是幂等的，重复执行会写重。

关键位置在 OrderBackfillJob.java:22，它直接 INSERT，没有基于 orderNo 的去重。调用链是这样的：

  1. JobScheduler.java:41 定时触发
  2. OrderBackfillJob.run() 拉未回填订单
  3. OrderRepo.insert() 逐条写入（问题点）

如果调度重试或人工重跑，同一个 orderNo 会被插两次。

修法是给 orderNo 建唯一索引，写库改成 upsert：

java 
// OrderRepo.java
@Insert("INSERT INTO member_order(order_no, uid, amount) "
      + "VALUES(#{orderNo},#{uid},#{amount}) "
      + "ON DUPLICATE KEY UPDATE amount=VALUES(amount)")
int upsertByOrderNo(Order o);
